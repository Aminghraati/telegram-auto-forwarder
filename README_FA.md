# 📱 اتوماسیون فوروارد سیو مسیج تلگرام (بدون نیاز به API)

این اسکریپت با **اکانت شخصی تلگرام شما** کار می‌کنه و دقیقاً **۵ پیام آخر سیو مسیج** رو — **بدون هیچ تغییری در متن یا عکس** — به‌صورت **موازی (هم‌زمان)** به همه گروه‌های یک پوشه تلگرام فوروارد می‌کنه.

## ✨ ویژگی‌ها

- ⚡ **ارسال موازی**: همه گروه‌ها در کمتر از ۱-۲ ثانیه پیام رو می‌گیرن — تعداد گروه‌ها تأثیری روی سرعت نداره
- ⏱️ **تاخیر تصادفی** بین پیام‌ها (قابل تنظیم — پایین‌تر توضیح دادم)
- 🔒 **بدون نیاز به API ID** از my.telegram.org — از اعتبارنامه رسمی Telegram Desktop استفاده می‌شه
- 📷 **ورود با QR** — بدون کد پیامکی و کپچا
- 🔁 **حلقه بی‌وقفه** — تا خودت متوقفش نکنی، دور پشت دور ادامه می‌ده
- 📥 **متن‌های مرجع از سیو مسیج** — فقط پیام جدید توی سیو مسیج بذار، دور بعد خودکار فوروارد می‌شه
- 🛑 **توقف از راه دور** — از گوشی با پیام `/stop` در سیو مسیج
- 🆕 **گروه‌های جدید خودکار شامل می‌شن** — هر گروهی که به پوشه اضافه کنی، از دور بعد فوروارد می‌گیره

---

## 🗺️ نقشه راه کامل (برای اکانت جدید)

### پیش‌نیازها

1. **Python 3.8+** روی سیستم نصب باشه → [python.org/downloads](https://www.python.org/downloads/)
   > موقع نصب، تیک **"Add Python to PATH"** رو حتماً بزن!
2. **تلگرام دسکتاپ** نصب باشه (برای ورود اولیه با QR لازم می‌شه) → [desktop.telegram.org](https://desktop.telegram.org/)
3. اینترنتی که به تلگرام وصل بشه (پراکسی/فیلترشکن — پایین‌تر توضیح دادم)

### مرحله ۱: دانلود پروژه و نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### مرحله ۲: تنظیم شماره تلفن

فایل `telethon_config.py` رو باز کن (با Notepad یا هر ادیتوری) و این خط رو پیدا کن:

```python
PHONE_NUMBER = "+98XXXXXXXXXX"
```

شماره خودت رو با کد کشور بنویس. مثلاً:

```python
PHONE_NUMBER = "+989121234567"
```

### مرحله ۳: ساخت پوشه «گپ» در تلگرام

1. توی تلگرام (دسکتاپ یا گوشی) روی نوار پوشه‌های بالا **راست‌کلیک** کن → **Create Folder** (ساخت پوشه)
2. اسمش رو بذار: **گپ**
3. گروه‌های هدف رو داخلش **Add** کن

> 💡 اگر اسم پوشه‌ات چیز دیگه‌ایه، توی `telethon_config.py` خط `FOLDER_NAME = "گپ"` رو با همون اسم عوض کن — باید **دقیقاً مثل** اسم پوشه در تلگرام باشه.

### مرحله ۴: آماده‌سازی سیو مسیج

- چند پیام (حداکثر ۵ تا) توی **سیو مسیج** خودت ذخیره کن — متن، عکس، ویدیو، هرچی
- اسکریپت **دقیقاً ۵ پیام آخر** رو (از جدید به قدیمی‌تر) فوروارد می‌کنه

### مرحله ۵: اتصال اینترنت به تلگرام

اسکریپت **خودش** پراکسی سیستم رو شناسایی می‌کنه:

- ✅ اگر اینترنتت **پراکسی‌دار** باشه (هات‌اسپات موبایل با فیلترشکن، یا پراکسی ویندوز) → خودکار استفاده می‌کنه
- ✅ اگر **VPN سراسری** (مثل ExpressVPN) وصل کنی → مستقیم کار می‌کنه
- ⚙️ پراکسی دستی هم داری؟ توی `telethon_config.py` بخش `PROXY` هست — `"enabled": True` کن و پرت بده

برای تست سریع اتصال:

```bash
python check_connection.py
```

اگر نوشت `[OK] TELEGRAM REACHABLE` یعنی آماده‌ای. ✅

### مرحله ۶: ورود با QR (فقط یک بار!)

```bash
python login.py qr
```

1. یه **کد QR بزرگ** توی ترمینال می‌بینی + فایل `login_qr.png` هم باز می‌شه
2. گوشی رو بردار → توی تلگرام گوشی: **تنظیمات → دستگاه‌ها → اتصال دستگاه دسکتاپ** (Settings → Devices → Link Desktop Device)
3. دوربین رو روی کد QR بگیر
4. وقتی نوشت: `QR_LOGIN_OK: [اسم شما]` یعنی تموم شد! 🎉

> ⚠️ کد QR حدود ۳۰ ثانیه اعتبار داره و خودش تازه می‌شه — اگه منقضی شد، پیام «QR تازه شد» می‌بینی و دوباره اسکن کن. ۲ دقیقه فرصت داری.
>
> 🔒 بعد از این مرحله، فایل `my_telegram.session` ساخته می‌شه — **این فایل کلید اکانتت هست، هرگز به کسی نده و هرگز کامیت نکن!**

### مرحله ۷: اجرا! 🚀

```bash
python send_to_folder.py
```

یا ساده‌تر: **دابل‌کلیک روی `start.bat`**

خروجی باید چیزی شبیه این باشه:

```
🔎 بررسی اتصال به سرور تلگرام...
✅ دسترسی تأیید شد (از طریق پراکسی سیستم ...)
🔗 در حال اتصال به تلگرام...
✅ با اکانت [اسم شما] متصل شد!
🚀 اتوماسیون فوروارد شروع به کار کرد!

📨 فوروارد موازی پیام «...» به 6 گروه:
  ↳ این پیام به 6/6 گروه رسید در 0.8 ثانیه
  ⏱️ 19 ثانیه صبر برای پیام بعدی...
```

### توقف

دو راه:

1. توی پنجره اجرا: **Ctrl+C**
2. از راه دور (حتی از گوشی): توی **سیو مسیج** پیام **`/stop`** بفرست — دور بعد اسکریپت خودش می‌ایسته ⛔
   > برای شروع دوباره: پیام `/stop` رو از سیو مسیج **پاک کن** و اسکریپت رو دوباره اجرا کن

## ⏱️ تنظیم تایمر (تغییر زمان تاخیر بین پیام‌ها)

**فایل:** `telethon_config.py`

این بخش رو پیدا کن:

```python
FORWARD_CONFIG = {
    "min_delay": 15,     # حداقل تاخیر (ثانیه)
    "max_delay": 25,     # حداکثر تاخیر (ثانیه)
    ...
}
```

- `min_delay` = **کمترین** زمان صبر بین دو پیام (برحسب ثانیه)
- `max_delay` = **بیشترین** زمان صبر (اسکریپت یه عدد تصادفی بین این دو تا انتخاب می‌کنه)

### 📝 مثال: تاخیر ۲ تا ۳ دقیقه

هر **۱ دقیقه = ۶۰ ثانیه**، پس ۲ دقیقه = ۱۲۰ و ۳ دقیقه = ۱۸۰. دقیقاً اینطوری بنویس:

```python
FORWARD_CONFIG = {
    "min_delay": 120,    # ۲ دقیقه
    "max_delay": 180,    # ۳ دقیقه
    ...
}
```

### مثال‌های دیگه:

| می‌خوای تاخیر بین... | min_delay | max_delay |
|---|---|---|
| ۵ تا ۱۰ ثانیه | `5` | `10` |
| ۳۰ ثانیه تا ۱ دقیقه | `30` | `60` |
| ۱۰ تا ۱۵ دقیقه | `600` | `900` |
| ۲ تا ۳ دقیقه (همون مثال بالا) | `120` | `180` |

> ⚠️ **فقط اعداد رو عوض کن** — بقیه خطوط (کاما، کوتیشن، دندانه‌گذاری) دست نخوره وگرنه برنامه خطا می‌ده.
>
> ذخیره کن → اسکریپت رو دوباره اجرا کن. تمام.

### سایر تنظیمات مهم در همین فایل:

```python
PHONE_NUMBER = "+98XXXXXXXXXX"   # شماره تلفن اکانت (با کد کشور)
FOLDER_NAME = "گپ"               # نام پوشه هدف
"message_count": 5,              # چند پیام آخر سیو مسیج فوروارد بشه
"max_broadcast_seconds": 20,     # سقف زمان ارسال موازی هر پیام (معمولاً دست نزن)
```

## 📂 تغییر اسم پوشه هدف

اسکریپت همه فورواردها رو به گروه‌های **یک پوشه خاص تلگرام** می‌فرسته. اسم این پوشه توی فایل `telethon_config.py` با تنظیم `FOLDER_NAME` تعیین می‌شه:

```python
FOLDER_NAME = "گپ"   # اسم پوشه‌ای که گروه‌های هدف داخلشه
```

### 📝 مثال ۱: پوشه با اسم «تبلیغات»

اگه توی تلگرامت یه پوشه به اسم **تبلیغات** ساختی و می‌خوای فورواردها برن داخل اون، فقط همین خط رو عوض کن:

```python
FOLDER_NAME = "تبلیغات"
```

### 📝 مثال ۲: پوشه با اسم انگلیسی مثل `Work Groups`

اسم پوشه هرچی می‌تونه باشه — فارسی یا انگلیسی، فقط باید **دقیقاً و حرف‌به‌حرف** مثل اسمی که توی تلگرام گذاشتی نوشته شه (فاصله‌ها و بزرگی/کوچیکی حروف مهمه):

```python
FOLDER_NAME = "Work Groups"
```

### 📝 مثال ۳: عوض کردن هم‌زمان اسم پوشه و تایمر (۲ تا ۳ دقیقه)

فرض کن می‌خوای هم پوشه رو ببری روی «کار» و هم تاخیر بین پیام‌ها بشه ۲ تا ۳ دقیقه. کل بخش مربوطه توی `telethon_config.py` این شکلی می‌شه:

```python
FOLDER_NAME = "کار"

FORWARD_CONFIG = {
    "min_delay": 120,    # ۲ دقیقه
    "max_delay": 180,    # ۳ دقیقه
    "message_count": 5,
    "max_broadcast_seconds": 20,
}
```

### نکته‌های مهم درباره اسم پوشه

1. پوشه باید **از قبل توی تلگرامت ساخته شده باشه** (راست‌کلیک روی نوار پوشه‌ها → Create Folder) و گروه‌های هدف رو داخلش Add کرده باشی
2. اگر اسم توی کانفیگ با اسم واقعی پوشه **حتی یک حرف فرق** داشته باشه، اسکریپت خطای `پوشه یافت نشد` می‌ده و لیست پوشه‌هات رو نشونت می‌ده تا اسم درست رو کپی کنی
3. هر وقت اسم پوشه رو عوض کردی، فقط فایل رو ذخیره کن و اسکریپت رو دوباره اجرا کن — نیاز به کار دیگه‌ای نیست
4. گروه‌هایی که بعداً به پوشه اضافه/حذف می‌کنی هم خودکار اعمال می‌شن (لیست عضوها در شروع هر دور دوباره خونده می‌شه)

## 🔒 امنیت — خیلی مهم!

1. **فایل `my_telegram.session` = کلید کامل اکانتت.** هر کسی این فایل رو داشته باشه می‌تونه با اکانتت پیام بفرسته. هرگز: ایمیل نکن، تلگرام نکن، **کامیت نکن، در گیت‌هاب نذار!** (فایل `.gitignore` موجود در پروژه جلوی کامیت تصادفیش رو می‌گیره)
2. این خطاها رو دیدی یعنی تلگرام محدودت کرده: پیام نمی‌ره، `FloodWaitError`، یا گروه‌ها پیام نمی‌گیرن → **`/stop` بزن** و چند ساعت صبر کن
3. سرعت خیلی زیاد + پیام تکراری در گروه‌های فعال = احتمال گزارش شدن و محدودیت اکانت. تاخیر ۱۵-۲۵ ثانیه برای شروع مناسبه؛ اگر اکانتت جاافتاده نیست، محافظه‌کارتر باش
4. اکانت‌های **تازه‌ساخت** حساس‌ترن؛ با اکانت جاافتاده راحت‌تره
5. اگر روی **چند اکانت** استفاده می‌کنی، هر اکانت توی **پوشه جدا** با session جدا باشه

## 🧰 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `❌ اتصال به سرور تلگرام ممکن نیست` | فیلترشکن/پراکسی رو وصل کن، بعد `python check_connection.py` تا `[OK]` ببینی |
| `[BLOCKED]` با وجود پراکسی | مطمئن شو تلگرام دسکتاپ خودش کار می‌کنه — اگر اون کار می‌کنه و اسکریپت نه، پراکسی دستی رو توی کانفیگ ست کن |
| `database is locked` | یه اجرای دیگه از اسکریپت بازه — Task Manager → python.exe رو ببند |
| `پوشه «گپ» یافت نشد` | اسم پوشه در `FOLDER_NAME` باید دقیقاً مثل تلگرام باشه (فاصله‌ها و حروف!) |
| `⚠️ نتوانستم این عضو پوشه را باز کنم: private` | از اون گروه خارج شدی یا بن شدی — از پوشه تلگرامش رو حذف کن |
| `QR تازه شد` مدام | کد فقط ۲ دقیقه اعتباره — دوربین رو از قبل آماده کن و سریع اسکن کن |
| `PHONE_NUMBER_UNOCCUPIED` | شماره رو با کد کشور بزن: `+98...` |

## ❓ سوالات رایج

**بدون API ID واقعاً کار می‌کنه؟**
بله — از اعتبارنامه عمومی و رسمی Telegram Desktop استفاده می‌شه که داخل سورس متن‌باز تلگرام منتشر شده. از نظر سرور تلگرام، اسکریپت مثل تلگرام دسکتاپ دیده می‌شه.

**اگه پیام جدید توی سیو مسیج بذارم؟**
دور بعد خودش پیام‌ها رو دوباره می‌خونه و جدیدها رو فوروارد می‌کنه — نیازی به ری‌استارت نیست.

**گروه جدید به پوشه اضافه کنم چی؟**
از دور بعد خودکار شامل می‌شه — بدون ری‌استارت.

**کد پیامکی هم لازمه؟**
نه — فقط QR. (اگر خواستی، `python login.py send_code` و `python login.py verify کد` هم هست ولی معمولاً کپچا می‌خواد؛ QR همیشه کار می‌کنه)

**روی اکانت دیگه چطور ببرمش؟**
همون مراحل بالا: پوشه جدید → شماره جدید در کانفیگ → `python login.py qr` با گوشی اون اکانت → تمام. هرگز فایل session اکانت قبلی رو کپی نکن!
