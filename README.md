# 📱 اتوماسیون فوروارد سیو مسیج تلگرام (بدون نیاز به API)

این اسکریپت با **اکانت شخصی تلگرام شما** کار می‌کند و **۵ پیام آخر سیو مسیج** را — بدون هیچ تغییری در متن یا عکس — به‌صورت **هم‌زمان (موازی)** به همه گروه‌های یک پوشه تلگرام فوروارد می‌کند. فاصله بین پیام‌ها تصادفی است و اسکریپت تا وقتی خودتان متوقفش نکنید، دور پشت دور ادامه می‌دهد.

---

## 📁 هر فایل چه کاری انجام می‌دهد؟ (فایل‌هایی که برای تغییرات لازم دارید)

| فایل | کارش چیست | آیا تغییرش می‌دهید؟ |
|---|---|---|
| `telethon_config.py` | **تنظیمات اصلی** — شماره تلفن، اسم پوشه، تایمر | ✅ بله، همه تنظیمات اینجاست |
| `send_to_folder.py` | برنامه اصلی — فوروارد را اجرا می‌کند | ❌ فقط اجرا می‌کنید |
| `login.py` | ورود با QR (اتصال اکانت بدون API) | ❌ فقط یک بار اجرا می‌کنید |
| `check_connection.py` | تست اتصال اینترنت به تلگرام | ❌ فقط برای تست |
| `start.bat` | اجرای برنامه با دابل‌کلیک در ویندوز | ❌ |
| `requirements.txt` | لیست کتابخانه‌های مورد نیاز | ❌ |
| `my_telegram.session` | 🔑 کلید ورود شما (خودکار ساخته می‌شود) | ❌ **هرگز به کسی ندهید و آپلود نکنید!** |

> 💡 **خلاصه:** برای هر تغییری فقط فایل `telethon_config.py` را با Notepad باز می‌کنید و چند عدد/کلمه را عوض می‌کنید. همین!

## 🚀 راه‌اندازی صفر تا صد روی اکانت جدید

### پیش‌نیازها

1. **Python 3.8 یا بالاتر** → از [python.org/downloads](https://www.python.org/downloads/) نصب کنید
   > ⚠️ موقع نصب، تیک **Add Python to PATH** را حتماً بزنید!
2. **تلگرام دسکتاپ** روی همان کامپیوتر نصب باشد (برای دیدن QR) → [desktop.telegram.org](https://desktop.telegram.org/)
3. اینترنتی که به تلگرام وصل شود (اگر در ایران هستید، همان اینترنتی که تلگرام دسکتاپ‌تان با آن کار می‌کند کافی است — اسکریپت پراکسی سیستم را خودکار پیدا می‌کند)

### مرحله ۱: نصب کتابخانه‌ها

پوشه پروژه را باز کنید، در نوار آدرس پوشه بنویسید `cmd` و Enter بزنید. در پنجره سیاه:

```bash
pip install -r requirements.txt
```

### مرحله ۲: تنظیم شماره تلفن

فایل `telethon_config.py` را با Notepad باز کنید و این خط را پیدا کنید:

```python
PHONE_NUMBER = "+98XXXXXXXXXX"
```

شماره خودتان را با کد کشور بنویسید:

```python
PHONE_NUMBER = "+989121234567"
```

### مرحله ۳: ساخت پوشه گروه‌ها در تلگرام

1. در تلگرام، روی نوار پوشه‌های بالای چت‌ها **راست‌کلیک** کنید → **Create Folder**
2. یک اسم بدهید (مثلاً: `گپ`)
3. همه گروه‌های هدف را داخلش **Add** کنید

> اسم پوشه هر چه باشد، فقط باید با تنظیمات اسکریپت یکی باشد (پایین‌تر توضیح داده شده).

### مرحله ۴: آماده‌سازی سیو مسیج

- پیام‌های مورد نظر (متن، عکس، ویدیو — هر چیزی) را در **سیو مسیج** خود ذخیره کنید
- اسکریپت **دقیقاً ۵ پیام آخر** را فوروارد می‌کند
- هر وقت پیام‌های جدیدی در سیو مسیج بگذارید، دور بعد خودشان فوروارد می‌شوند — نیاز به ری‌استارت نیست

### مرحله ۵: تست اتصال

```bash
python check_connection.py
```

- اگر نوشت `[OK] TELEGRAM REACHABLE` → آماده‌اید ✅
- اگر نوشت `[BLOCKED]` → فیلترشکن/VPN را وصل کنید و دوباره تست کنید

### مرحله ۶: اتصال اکانت تلگرام — بدون API، فقط با QR 📷

برای این اسکریپت **نیازی به سایت my.telegram.org و گرفتن API ID نیست** — از اعتبارنامه رسمی تلگرام دسکتاپ استفاده می‌شود و ورود فقط با QR انجام می‌شود:

```bash
python login.py qr
```

بعد:

1. یک **کد QR** نمایش داده می‌شود (هم در ترمینال، هم به‌صورت پنجره عکس)
2. گوشی را بردارید → در تلگرام گوشی: **تنظیمات → دستگاه‌ها → اتصال دستگاه دسکتاپ** (Settings → Devices → Link Desktop Device)
3. دوربین گوشی را روی QR بگیرید
4. وقتی نوشت `QR_LOGIN_OK` یعنی وصل شدید 🎉

> ⚠️ QR حدود ۲ دقیقه اعتبار دارد؛ اگر منقضی شد، دستور را دوباره اجرا کنید.
>
> 🔒 بعد از این مرحله فایل `my_telegram.session` ساخته می‌شود. این فایل یعنی «کلید اکانت شما» — از این به بعد دیگر هیچ‌وقت لازم نیست لاگین کنید.

برای اطمینان از وضعیت لاگین:

```bash
python login.py status
```

### مرحله ۷: اجرا! 

```bash
python send_to_folder.py
```

یا ساده‌تر: **دابل‌کلیک روی فایل `start.bat`**

خروجی موفق باید چیزی شبیه این باشد:

```
✅ دسترسی تأیید شد (از طریق پراکسی سیستم ...)
✅ با اکانت [اسم شما] متصل شد!
🚀 اتوماسیون فوروارد شروع به کار کرد!
📨 پیام ۱ → 6 گروه (هم‌زمان): ✅ 6/6 رسید
⏱️ 19 ثانیه صبر...
```

### ⛔ توقف

دو راه دارید:

1. در پنجره اجرا: **Ctrl+C**
2. از راه دور (حتی با گوشی): در **سیو مسیج** پیام `/stop` بفرستید — دور بعد اسکریپت می‌ایستد
   > برای شروع دوباره: پیام `/stop` را از سیو مسیج پاک کنید و دوباره اجرا کنید

## 📂 تغییر اسم پوشه هدف

اسکریپت به گروه‌های **یک پوشه مشخص** پیام می‌فرستد. اسم این پوشه در فایل `telethon_config.py` با تنظیم `FOLDER_NAME` تعیین می‌شود:

```python
FOLDER_NAME = "گپ"
```

**قانون مهم:** اسم باید **دقیقاً و حرف‌به‌حرف** مثل اسم پوشه‌ای که در تلگرام ساخته‌اید نوشته شود — فاصله‌ها و حروف بزرگ/کوچک مهم است.

### مثال ۱: پوشه‌ای به اسم «تبلیغات»

در تلگرام پوشه «تبلیغات» را ساخته‌اید؟ فقط این خط را عوض کنید:

```python
FOLDER_NAME = "تبلیغات"
```

### مثال ۲: پوشه با اسم انگلیسی

اگر اسم پوشه در تلگرام `Work Groups` باشد:

```python
FOLDER_NAME = "Work Groups"
```

### نکته‌ها

- پوشه باید **از قبل در تلگرام ساخته شده باشد** و گروه‌های هدف داخلش باشند
- اگر اسم اشتباه باشد، اسکریپت پیام «پوشه یافت نشد» می‌دهد و لیست پوشه‌های واقعی شما را نشان می‌دهد — اسم درست را از همان‌جا کپی کنید
- بعد از تغییر: ذخیره کنید → اسکریپت را دوباره اجرا کنید. تمام
- گروهی که بعداً به پوشه اضافه یا ازش حذف کنید، از **دور بعد** خودکار اعمال می‌شود (لیست در شروع هر دور دوباره خوانده می‌شود)

## ⏱️ تغییر تایم فوروارد (تاخیر بین پیام‌ها)

تاخیر بین پیام‌ها **تصادفی** است — اسکریپت هر بار یک عدد بین حداقل و حداکثر انتخاب می‌کند تا معلوم نباشد ربات است. این دو عدد در فایل `telethon_config.py` داخل بخش `FORWARD_CONFIG` هستند:

```python
FORWARD_CONFIG = {
    "min_delay": 15,     # حداقل تاخیر (ثانیه)
    "max_delay": 25,     # حداکثر تاخیر (ثانیه)
    "message_count": 5,
    "max_broadcast_seconds": 20,
}
```

**قانون تبدیل:** هر ۱ دقیقه = ۶۰ ثانیه. یعنی ۲ دقیقه = `120` و ۳ دقیقه = `180`.

### مثال کامل: تاخیر ۲ تا ۳ دقیقه

دقیقاً این شکلی بنویسید:

```python
FORWARD_CONFIG = {
    "min_delay": 120,    # ۲ دقیقه
    "max_delay": 180,    # ۳ دقیقه
    "message_count": 5,
    "max_broadcast_seconds": 20,
}
```

### جدول مثال‌های آماده

| می‌خواهید تاخیر بین... | `min_delay` | `max_delay` |
|---|---|---|
| ۵ تا ۱۰ ثانیه | `5` | `10` |
| ۱۵ تا ۲۵ ثانیه (پیش‌فرض فعلی) | `15` | `25` |
| ۳۰ ثانیه تا ۱ دقیقه | `30` | `60` |
| ۲ تا ۳ دقیقه | `120` | `180` |
| ۱۰ تا ۱۵ دقیقه | `600` | `900` |

> ⚠️ **فقط اعداد را عوض کنید** — کاما، کوتیشن و تورفتگی‌ها دست نخورند وگرنه برنامه خطا می‌دهد.
>
> بعد از تغییر: ذخیره → اجرای دوباره. نیازی به کار دیگری نیست.

### تنظیم دیگر: تعداد پیام‌ها

اگر نمی‌خواهید ۵ پیام فوروارد شود، `"message_count": 5` را تغییر دهید (مثلاً `3` یعنی فقط ۳ پیام آخر).

## 🔒 امنیت — خیلی مهم

1. فایل `my_telegram.session` = **کلید کامل اکانت شما**. هرگز: ایمیل نکنید، در تلگرام نفرستید، در گیت‌هاب آپلود نکنید، به کسی ندهید
2. اگر پیام‌ها ارسال نشدند یا خطای `FloodWaitError` دیدید، یعنی تلگرام موقتاً محدودتان کرده → `/stop` بزنید و چند ساعت صبر کنید
3. سرعت خیلی بالا + پیام تکراری در گروه‌های فعال = احتمال گزارش شدن و محدودیت اکانت. برای اکانت‌های تازه‌ساخت، تاخیر را بزرگ‌تر بگیرید
4. اگر روی **چند اکانت** استفاده می‌کنید، هر اکانت در **پوشه جداگانه** باشد (چون session هر اکانت جدا است)

## 🧰 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `[BLOCKED]` در تست اتصال | فیلترشکن/VPN را وصل کنید و دوباره `python check_connection.py` |
| `پوشه یافت نشد` | اسم در `FOLDER_NAME` باید دقیقاً مثل تلگرام باشد (لیست پوشه‌ها در همان خطا نمایش داده می‌شود) |
| `database is locked` | یک اجرای دیگر باز است → Task Manager → `python.exe` را ببندید |
| QR مدام منقضی می‌شود | دوربین گوشی را از قبل آماده کنید و سریع اسکن کنید |
| شماره پذیرفته نمی‌شود | با کد کشور بنویسید: `+98...`
